# LATTICE 待办

当前框架先固定数据协议和可运行流程。下列工作按可独立验证的方向排列，不承诺论文结果，也不将占位策略描述为已完成的方法创新。

## 第一阶段：替换默认父节点策略

- [ ] 为现有启发式和 LLM 选择器建立可复现的路由评估。
- [ ] 增加词法与向量混合候选召回、重排序，降低全历史扫描成本。
- [ ] 研究父节点集合的联合选择，区分互补证据与重复证据。
- [ ] 研究基于证据覆盖、预算约束和最小依赖集的选择策略。
- [ ] 利用既有 DAG 找回语义相似度低但必要的上游依赖。
- [ ] 增加 learned selector；保留启发式回退和不确定性记录。
- [ ] 评估不选择父节点、单父、多父的判定，以及隐式指代和旧话题返回。

## 第二阶段：上下文管理

- [ ] 从截取摘要升级为查询相关、可回溯原文的 LLM 压缩。
- [ ] 选择原文、片段、摘要的粒度与预算，处理共享祖先重复信息。
- [ ] 接入模型 tokenizer，区分输入预算、回答预算与工具执行预算。
- [ ] 为原文片段保留稳定引用，支持回答片段级追问。
- [ ] 明确分支假设、约束作用域、局部修订、冲突与选择性合并语义。
- [ ] 记录压缩版本、来源和适用问题，避免摘要覆盖后无法复现实验。
- [ ] 检查逐轮长会话的成本、延迟和历史增长行为。

## 完成标准建议

首先验证人工依赖能否改善目标任务；再验证自动选择能否接近这一上限；最后确认收益是否足以覆盖建图和压缩的额外成本。各模块保留独立配置，避免界面、模型和上下文策略同时变化而无法判断改进来源。
